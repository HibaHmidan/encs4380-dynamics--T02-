Module 3: Second-Order Response

Mass-spring-damper: m x'' + b x' + k x = F(t).
G(s) = K ωn² / (s² + 2ζωn s + ωn²)
ωn = √(k/m), ζ = b / (2√(km)), K = 1/k.

k is spring stiffness (N/m); K = 1/k is static gain (m/N). The step force has amplitude A = k newtons, so the final displacement K·A = 1 m. Changing k also changes this step force. The system starts at rest. Rise time uses 10%–90%; settling time uses a ±5% band.

Predict, then check

Start with an underdamped system (ζ < 1). Keep m and k fixed and increase b toward critical damping. What happens to overshoot? Choose a prediction, try the b slider, then check.

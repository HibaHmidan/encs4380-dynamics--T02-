Module 3: Second-Order Response

Mass-spring-damper: m x'' + b x' + k x = F(t).
G(s) = K ωn² / (s² + 2ζωn s + ωn²),
ωn = √(k/m), ζ = b / (2√(km)), K = 1/k.

Here k is the spring stiffness (N/m), while K = 1/k is the static gain from force to displacement (m/N). We choose a step force A = k newtons, so the final displacement K·A = 1 m. The system starts at rest; the step plot shows y/(K·A). Rise time uses 10% to 90%; settling time uses a ±5% band.

Predict, then check

Start with an underdamped system (ζ < 1). Keep m and k fixed and increase b toward critical damping. What happens to the overshoot? Predict first, then try the example buttons or the b slider.
